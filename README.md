# دادیار AI | سامانه هوشمند تصحیح پاسخ‌برگ

سامانه فارسی و راست‌چین برای مدیریت آزمون، تعریف کلید، ثبت پاسخ‌ها و محاسبه نمره. این مخزن نقطه شروع نسخه قابل توسعه دادیار AI است.

## وضعیت فعلی
- داشبورد فارسی واکنش‌گرا
- تعریف کلید پاسخ و پاسخ دانش‌آموز
- محاسبه نمره با ضریب نمره منفی ۳
- پاسخ خالی بدون جریمه
- ذخیره آزمایشی داده‌ها در مرورگر (localStorage)
- فایل پایه SQL برای Supabase
- اسکلت سرویس پردازش تصویر با FastAPI

> توجه: در این نسخه، تصحیح پاسخ‌های واردشده در فرم انجام می‌شود. خواندن خودکار پاسخ‌برگ از تصویر/PDF، تولید QR اختصاصی، احراز هویت و اتصال واقعی Supabase هنوز پیاده‌سازی و آزمایش نشده‌اند.

## اجرای محلی رابط
فایل `index.html` را در مرورگر باز کنید یا پروژه را روی Vercel متصل کنید. این نسخه فرانت‌اند ایستا است و به build command نیاز ندارد.

## ساختار
- `index.html` رابط کاربری
- `supabase/schema.sql` ساختار اولیه پایگاه داده
- `omr-service/main.py` اسکلت API پردازش پاسخ‌برگ
- `omr-service/requirements.txt` وابستگی‌های سرویس پردازش تصویر

## تنظیمات آزمون
- تعداد گزینه‌ها: ۴ (۱ تا ۴)
- ضریب نمره منفی: ۳
- پاسخ خالی: صفر
- فرمول نمره خام: پاسخ صحیح − (پاسخ غلط ÷ ۳)
- پاسخ‌های چندعلامتی/نامطمئن باید برای بررسی انسانی علامت‌گذاری شوند؛ سیستم نباید حدس بزند.

## اتصال Supabase
۱. یک پروژه Supabase مستقل برای دادیار بسازید.
۲. فایل `supabase/schema.sql` را در SQL Editor اجرا کنید.
۳. مقادیر `SUPABASE_URL` و `SUPABASE_SERVICE_ROLE_KEY` را فقط در متغیرهای محیطی امن سرویس سرور قرار دهید؛ کلید service role را در مرورگر یا GitHub قرار ندهید.

## سرویس OMR
در پوشه `omr-service`:
```bash
pip install -r requirements.txt
uvicorn main:app --reload
```
این API فعلاً اسکلت دریافت فایل است؛ الگوریتم واقعی تشخیص حباب، اصلاح پرسپکتیو و خواندن QR در مرحله بعد باید تکمیل و با نمونه‌برگه‌های واقعی آزموده شود.

## استقرار
در Vercel، مخزن `amiraliwq/dadyar-ai` را Import کنید. برای نسخه ایستا، Framework Preset را روی Other و Build Command را خالی بگذارید.
