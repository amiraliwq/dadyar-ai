# دادیار AI | سامانه مدیریت و تصحیح هوشمند آزمون

سامانه فارسی و راست‌چین برای مدیریت مدرسه، کلاس‌ها، دانش‌آموزان، آزمون‌ها، پاسخ‌برگ‌های QRدار، تصحیح OMR و گزارش Excel.

## ساختار پروژه
- index.html — داشبورد واکنش‌گرا، ورود/ثبت‌نام، مدیریت آزمون‌ها و دانش‌آموزان، تولید پاسخ‌برگ، تصحیح و گزارش.
- api/config.js — ارائه تنظیمات عمومی Supabase و نشانی OMR به فرانت‌اند؛ فقط URL و کلید عمومی منتشر می‌شوند.
- supabase/schema-v2.sql — ساختار چندمستاجری پایگاه داده با RLS و فضای ذخیره‌سازی خصوصی.
- omr-service/main.py — سرویس FastAPI برای تولید PDF/QR، خواندن پاسخ‌برگ و ساخت Excel.
- omr-service/Dockerfile — بسته‌بندی سرویس OMR برای میزبانی کانتینری.

## راه‌اندازی Supabase
۱. یک پروژه اختصاصی با نام dadyar-ai بسازید؛ از پروژه‌های دیگر برای این سامانه استفاده نکنید.
۲. فایل supabase/schema-v2.sql را در SQL Editor پروژه اجرا کنید.
۳. در Vercel، متغیرهای محیطی زیر را برای پروژه وب ثبت کنید:

| متغیر | مقدار |
|---|---|
| SUPABASE_URL | Project URL |
| SUPABASE_ANON_KEY یا SUPABASE_PUBLISHABLE_KEY | کلید عمومی (Publishable/anon) |
| OMR_API_URL | آدرس عمومی سرویس OMR پس از استقرار |

۴. پس از تغییر متغیرها، یک deployment جدید بسازید.
۵. در Supabase Auth، روش ایمیل/رمز عبور را فعال کنید و آدرس سایت را در URL Configuration ثبت کنید.

**مهم:** کلید service_role یا secret key را در مرورگر، GitHub، index.html یا api/config.js قرار ندهید. فایل API فقط کلید عمومی Supabase را به مرورگر می‌دهد.

## استقرار سرویس OMR
سرویس Python مستقل از وب‌سایت Vercel اجرا می‌شود. در میزبان کانتینری که Docker و درخواست‌های ورودی حداقل ۱۵ مگابایت را پشتیبانی کند، پوشه omr-service را مستقر کنید.

متغیرهای محیطی الزامی سرویس:
- DADYAR_QR_SECRET — یک راز تصادفی قوی و طولانی؛ مقدار نمونه یا مقدار پیش‌فرض ناامن را استفاده نکنید.
- CORS_ORIGINS — فقط دامنه نهایی سایت، مانند https://dadyar-ai-web.vercel.app.
- DADYAR_FONT — مسیر فونت DejaVu Sans در کانتینر (Dockerfile مقدار پیش‌فرض دارد).
- PORT — پورت اختصاص‌داده‌شده توسط میزبان.

پس از استقرار، مسیر GET /health را بررسی کنید و نشانی ریشه سرویس را در تنظیمات دادیار وارد کنید.

## امکانات پیاده‌سازی‌شده در کد
- ورود و ثبت‌نام با Supabase Auth
- پروفایل و فضای کاری مستقل مدرسه
- مدیریت کلاس، دانش‌آموز، آزمون و کلید پاسخ
- تولید PDF اختصاصی با QR امضاشده برای هر دانش‌آموز
- خواندن تصویر/PDF، اصلاح پرسپکتیو با چهار نشانگر مرجع، تشخیص حباب و علامت‌گذاری پاسخ‌های مبهم
- ذخیره نتایج و وضعیت بازبینی در Supabase
- خروجی Excel گزارش‌ها

## وضعیت انتشار و آزمون
این مخزن در حال آماده‌سازی نسخه انتشار است. کد رابط و API پیکربندی در Vercel از GitHub ساخته می‌شود، اما قابلیت‌های وابسته به سرویس خارجی فقط پس از ساخت پروژه Supabase، اجرای SQL، ثبت متغیرهای محیطی و استقرار سرویس OMR فعال می‌شوند.

الگوریتم OMR باید با پاسخ‌برگ‌های چاپ‌شده و اسکن‌شده واقعی در چند کیفیت و زاویه آزمایش و کالیبره شود. پاسخ‌های مبهم نباید بدون بازبینی انسانی نهایی شوند. هیچ ادعای دقت ۱۰۰٪ مطرح نمی‌شود.
